# 눌러 — 한 손 클리커 스마트 단어장

블루투스 클리커(발표용 리모컨) 하나로 넘기고 뒤집는 **한 손 암기용 플래시카드** 웹앱입니다.
설치 없이 브라우저에서 바로 열리고, 단어장은 기기 안(localStorage)에만 저장됩니다.

**▶ 라이브: https://zizla.github.io/word_memory/**

## 앱으로 설치하기 (PWA)

안드로이드 크롬에서 주소를 열면 **「앱 설치」**, 아이폰 사파리에서는 **공유 → 홈 화면에 추가**가 뜹니다.
설치하면 주소창 없는 단독 창으로 뜨고(standalone), 한 번 열어 둔 앱 셸은 오프라인에서도 열립니다.
학습 기록·단어장은 설치 전과 같은 기기 저장소(localStorage)를 그대로 씁니다.

## 주요 기능

- **클리커 3모드** — ① 기본/방향키 모드(다버튼 리모컨: `→`·PgDn·Space 다음, `←`·PgUp 이전, `↑`·Enter 뒤집기, `↓` 발음) ② 원버튼 순환 모드(1버튼 링·셀카 리모컨으로 앞면 → 뜻 → 다음) ③ 커스텀 키 바인딩(원하는 리모컨 키를 직접 매핑). 키 테스트 모니터와 타건음·햅틱 피드백 포함.
- **✨ AI·온라인 단어 자동 가져오기** — 프리셋(비즈니스, AI·데이터, 식품·바이오, 일상회화, **수능 빈출 영단어**, 일본어 JLPT, **중국어 HSK·회화**, **프랑스어 필수·회화**)이나 직접 입력한 주제로 **10·30·50개**를 골라 **딸깍 한 번**에 단어·발음·뜻·예문까지 수집합니다. 무료 공개 API(MyMemory 번역, Datamuse, Free Dictionary)를 쓰므로 키가 필요 없고, 네트워크·CORS로 API가 막히면 안내 토스트와 함께 내장 확장 뱅크로 자동 대체되어 50개까지 끊김 없이 채워집니다.
- **언어별 내장 뱅크** — 영어 확장 뱅크 108개(주제별 27개), 일본어 85개, 중국어 63개(간체자+병음), 프랑스어 65개(IPA 발음), 수능 빈출 영단어 62개(IPA·품사·수능형 예문). 카드 발음(TTS)은 `zh → zh-CN`, `fr → fr-FR`, `ja → ja-JP`로 자동 매핑됩니다.
- **선택형 Gemini API 키 연동** — 자연어로 "식품 품질관리 현장 영단어 15개"처럼 요청해 단어장을 생성하려면 Gemini API 키를 앱 안에 등록하면 됩니다(미등록이어도 위 무료 수집은 그대로 동작). 키는 브라우저 저장소에만 보관되고 서버로 전송되지 않습니다.
- **한지 / 먹야 테마** — 종이결 라이트 테마와 어두운 다크 테마 전환, 목탁·타건음 선택.
- **4지선다 퀴즈** — 순차 학습·랜덤 셔플·다시 보기(★)와 함께 4지선다 점검 모드(숫자키 1~4 지원).
- **JSON / CSV / URL 공유** — JSON·CSV·TSV(엑셀·노션 붙여넣기) 가져오기·내보내기, GitHub Raw JSON 불러오기, `?deck=...` 공유 링크로 폰과 노트북에서 같은 단어장 열기.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체(단일 파일, 프레임워크·빌드 없음) |
| `manifest.webmanifest` | PWA 매니페스트(앱 이름·아이콘·단독 실행) |
| `sw.js` | Service Worker — 앱 셸 캐시·오프라인 폴백 (외부 API·CDN 은 통과) |
| `icons/` | 앱 아이콘 180·192·512·maskable 512 (한지 바탕 + 주인(朱印) 배지) |
| `tools/make_icons.py` | 아이콘 재생성 스크립트 (`python3 tools/make_icons.py`) |
| `README.md` | 이 문서 |

`gh-pages` 브랜치가 GitHub Pages 배포 브랜치입니다(`main`은 소스 보관용). 두 브랜치의 `index.html`·`manifest.webmanifest`·`sw.js`·`icons/`는 항상 동일하게 유지합니다. 앱을 고칠 때는 수정한 파일을 양쪽 브랜치에 반영하면 됩니다.

> Service Worker 는 사이트 루트(`/word_memory/`) 기준 상대 경로(`./`)로만 동작하므로 `file://` 로 열면 등록되지 않습니다. 로컬 확인은 `python3 -m http.server` 처럼 서버로 열어 주세요.
